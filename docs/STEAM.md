# Путь в Steam — чек-лист

## Что делаешь ты (нужен твой аккаунт и деньги)

- [ ] Зарегистрироваться в **Steamworks** (partner.steamgames.com), заполнить налоговые и банковские данные.
- [ ] Оплатить **Steam Direct** — $100 за игру (возвращается после $1000 выручки).
- [ ] Получить **App ID** игры.

## Что делаем вместе

- [ ] **Страница игры «Скоро выйдет»** — открыть как можно раньше, чтобы копить вишлисты.
  Нужно: капсулы (обложки: 920×430, 462×174, 1232×706, 748×896, библиотечные 600×900 и 3840×1240),
  минимум 5 скриншотов, трейлер, описание, теги (Souls-like, Tower Defense, Pixel Graphics, Difficult, Action).
  Страница проходит ревью Valve (несколько дней), и открыть её можно не раньше чем через 2 недели после оплаты.
- [ ] **Интеграция Steamworks** через GodotSteam: достижения, облачные сохранения (`user://save.json`), оверлей.
- [ ] **Steam Deck**: управление с геймпада (уже есть), читаемый текст на 1280×800, без обязательной клавиатуры.
- [ ] **Демо** для Steam Next Fest — первый регион целиком.
- [ ] **Загрузка билдов** через SteamPipe (`steamcmd` + depot для Windows и Linux) — можно автоматизировать в GitHub Actions.
- [ ] Возрастной рейтинг (анкета IARC в Steamworks), локализация (минимум RU + EN).

## Технически уже готово

- [x] Сборка Windows x86_64 и Linux x86_64 (один файл, данные встроены).
- [x] Рендер GL Compatibility — пойдёт на слабых ПК и Steam Deck.
- [x] Целочисленное масштабирование пикселей (1080p = ×4).
- [x] Геймпад с первого дня.
- [x] Автотесты и автосборка в GitHub Actions.
