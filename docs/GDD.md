# Оборона Кордона — дизайн-документ

> Рабочее название. Жанр: **хардкорная стратегия обороны крепости в реальном времени**.
> Платформа: **Steam** (Windows, Linux, Steam Deck). Вдохновение — манхва «Я стал тираном в защитной игре».

## Питч

Ты единственный, кто прошёл беспощадную стратегию, и теперь очнулся внутри неё: опальный принц в крепости
Кордон на краю Озера Чудовищ. Каждую ночь из воды выходят твари. Ты не сражаешься сам — ты **командуешь**:
днём нанимаешь и тренируешь героев, укрепляешь стены; ночью расставляешь гарнизон и решаешь,
когда каждый герой применит способность.

## Столпы

1. **Только командование.** Никакого прямого управления бойцом и никаких проверок реакции.
   Удар врага всегда попадает в цель — побеждает план, а не ловкость рук.
2. **Хардкорная сложность.** Мало ресурсов, много врагов, каждая ночь сильнее предыдущей.
   Уровней сложности нет.
3. **Решения с ценой.** Золото на героя или на ворота? Рыцарь в поле держит врагов, но рискует жизнью.
   Огонь мага сжигает и своих. Павший герой не возвращается.
4. **Честность.** Разведка заранее показывает состав ночи.

## Основной цикл

```
День (найм, тренировка, укрепления, разведка) → Ночь (оборона) → День → … → Босс
                                                     │
                                          поражение → переиграть ночь с утра
```

- **День**: герои полностью исцелены, ворота починены. Тратишь золото. Игра автоматически сохраняется.
- **Ночь**: волны врагов из озера. Золото за каждого убитого.
- **Поражение** — падение ворот. Ночь можно переиграть: всё откатывается к утру этого дня
  (включая павших за эту ночь героев).
- **Павшие в выигранной ночи** остаются павшими навсегда.

## Командование

| Действие | Мышь | Клавиатура |
|----------|------|------------|
| Выбрать героя | ЛКМ по герою или карточке | 1–6 |
| Приказать идти | ЛКМ / ПКМ по земле | — |
| Способность | ЛКМ по карточке выбранного героя | Q |
| Цель способности | ЛКМ (ПКМ — отмена) | — |

- Поле боя: **поле** перед стеной и **стена**. Со стены стрелки и маги бьют на 25% дальше,
  и до них не дотянутся враги ближнего боя. Путь между стеной и полем — только через ворота.
- Герой в движении не атакует.
- Героев не больше 6. Редкость N / R / SR / SSR выпадает случайно при найме.

## Герои

| Класс | Роль | Способность |
|-------|------|-------------|
| Рыцарь | держит врагов в поле | **Вызов**: враги рядом бьют только его 4 с, урон по нему −50% |
| Лучник | дальний урон | **Залп**: град стрел по области |
| Маг | урон по площади | **Огненный дождь**: огромный урон через 1 с — **задевает своих** |
| Жрица | лечит раненых | **Молитва**: лечит всех |

## Враги (срез)

| Враг | Особенность |
|------|-------------|
| Утопленник | медленный широкий взмах |
| Гончая | быстрая, рывок с дистанции |
| Копейщик | длинный выпад, стойкий |
| Плевальщица | бьёт издалека, **достаёт героев на стене** |
| **Владыка Озера** (босс) | 2 фазы: взмах, удар по площади, во 2-й фазе рывок и призыв утопленников |

## День: на что тратить золото

- Найм героя (цена растёт с каждым наймом).
- Тренировка героя (+1 уровень).
- Лучники на башни (до 2) — автоматическая поддержка.
- Укрепление ворот (до 3 уровней).

## Масштаб полной игры (план)

- **5–7 регионов** (крепостей), в каждом 8–12 ночей и 1–2 босса.
- Строительство обороны: ловушки, башни, баррикады, рвы.
- Больше классов героев, черты характера, снаряжение.
- Указы тирана и репутация (тиран ↔ спаситель) → разные концовки.
- Режим «бесконечная оборона».

## Техника

- **Godot 4.5**, GDScript, рендер GL Compatibility (слабые ПК + Steam Deck).
- Внутреннее разрешение 480×270, целочисленное масштабирование (1080p = ×4).
- Управление: мышь + горячие клавиши; для Steam Deck — тачскрин/трекпад (схема для геймпада — в планах).
- Steamworks: GodotSteam — достижения, облачные сохранения, оверлей.
- Автотесты и бот-балансировщик: `godot --headless res://tests/tests.tscn`.
