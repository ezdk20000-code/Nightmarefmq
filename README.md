# Тиран Пограничья

Пиксельная tower defense, вдохновлённая манхвой «Я стал тираном в защитной игре».

Ты единственный, кто прошёл беспощадную игру, и теперь ты очнулся внутри неё: опальный принц
в крепости Кордон на краю Озера Чудовищ. Каждую ночь из воды выходят монстры.

## Как запустить

Открой `index.html` в браузере. Больше ничего не нужно: это один файл без зависимостей.

## Как играть

- **День**: нанимай героев (редкость N / R / SR / SSR выпадает случайно), расставляй их вдоль дороги,
  тренируй, ставь баррикады на дорогу, укрепляй стены.
- **Ночь**: монстры идут от озера к воротам, герои атакуют сами.
- **Утро**: издай указ. Налоги дают золото, но роняют мораль. От морали зависит скорость атаки,
  а если она упадёт ниже 20, герои начнут дезертировать.
- Цель: выстоять 10 ночей. Каждая 5-я ночь приходит Владыка Озера.

Классы героев: **Рыцарь** (ближний бой, бьёт по площади), **Лучник** (дальний бой), **Маг** (огненный шар со взрывом).
